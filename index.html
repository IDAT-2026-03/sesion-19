TEMA 1

CSS Grid: la cuadrícula que ordena todo

display: grid

Imagina una hoja de Excel dentro de tu página: filas y columnas. A esa hoja le decimos display: grid y cada hijo cae automáticamente en una celda.

1. El padre manda

Igual que en Flexbox: la cuadrícula se declara en el contenedor, no en las tarjetas.

2. Primero las columnas

1fr significa "una fracción del espacio libre". Tres 1fr = tres columnas iguales.

3. gap separa sin márgenes

Un solo valor y las celdas quedan parejas, sin tocar cada tarjeta.

Destacada · ocupa 2 columnas
celda 3
celda 4
celda 5
celda 6
3 columnas · 1fr cada una gap: 8px
estilos.css
<!-- HTML -->
<div class="galeria">
<div class="destacada">1</div>
<div>2</div>
…
</div>
/* CSS */
.galeria {
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 16px;
}
.destacada {
grid-column: span 2; /* 2 celdas */
}
💡 Grid vs Flexbox: Flexbox ordena en una dirección (fila o columna). Grid ordena en filas y columnas al mismo tiempo. Para galerías de tarjetas, Grid es el rey.

TEMA 2

El meta viewport: la pieza que falta

Sin esto, nada funciona

Si abres tu web en el celular y todo se ve diminuto, como una foto alejada, no es culpa de tu CSS: el navegador simula una pantalla de 980px y aleja el zoom para que "quepa".

❌ Sin la etiqueta:

El móvil asume 980px de ancho. Tus media queries de celular nunca se activan y el usuario tiene que hacer zoom con los dedos.

✅ Con la etiqueta:

El layout pasa a medir el ancho real del teléfono (375px, 390px…). Recién ahí max-width: 768px hace su trabajo.

⚠️ No bloquees el zoom:

Evita user-scalable=no y maximum-scale=1. Rompen la accesibilidad.

index.html
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<meta name="viewport"
content="width=device-width,
initial-scale=1.0">
<title>Mi Proyecto</title>
</head>
📌 En palabras simples: width=device-width → usa el ancho real de la pantalla.
initial-scale=1.0 → arranca sin zoom.
Tema 2: habilitar la pantalla real <meta name="viewport">
TEMA 3

Mobile First: todos los ajustes con max-width

De mayor a menor

En clase trabajamos así: escribimos los estilos base (los de la pantalla grande) y dentro de una sola sección de media queries vamos corrigiendo lo que se rompe al achicar. Así todos los cambios quedan en un mismo lugar y es fácil revisarlos.

BASE
Escritorio: 3 columnas · menú en fila
≤ 1024
2 columnas · márgenes más chicos
≤ 768
Menú en columna · 1 columna
≤ 480
Botones a lo ancho · texto más chico
¿min-width o max-width? Son dos caminos válidos: min-width parte del celular y crece; max-width parte del escritorio y achica. En clase usamos max-width porque concentra todos los ajustes en un solo bloque.
estilos.css
/* 1. BASE: la pantalla grande */
.tarjetas {
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 16px;
}
/* 2. Desde acá, todo se ajusta con max-width */
@media (max-width: 1024px) {
.tarjetas { grid-template-columns: repeat(2, 1fr); }
}
@media (max-width: 768px) {
.tarjetas { grid-template-columns: 1fr; }
.menu { flex-direction: column; }
}
@media (max-width: 480px) {
.menu a { width: 100%; }
}
Tema 3: una sola sección de ajustes Ordena siempre de 1024 → 768 → 480
TEMA 4

Media Queries: anatomía de un @media

el "si" del CSS
@media (max-width: 768px) { …reglas CSS… }
@media

Abre el bloque condicional.

(max-width: 768px)

La condición: "si la pantalla mide 768px o menos".

{ … }

Lo que se aplica solo si se cumple.

Los 4 operadores que importan

and

Se cumplen las dos: (min-width:481px) and (max-width:768px)

,

Basta una: (max-width:480px), (orientation:landscape)

not

Niega la consulta: not print

only

Comando heredado: only screen

Condiciones que puedes consultar

max-width min-width orientation prefers-color-scheme hover / pointer print
Sintaxis moderna por rangos (CSS 4)
/* celular: 480px o menos */
@media (width <= 480px) { … }
/* modo oscuro, sin JS */
@media (prefers-color-scheme: dark) { … }
Tema 4: regla + condición + bloque @media (max-width: 768px) { … }
TEMA 4 · EN PRÁCTICA

Nuestros 4 cortes y el orden del código

1024 · 768 · 480
Pantalla Corte Qué cambia
Escritorio sin media query 3 columnas · menú en fila · contenedor centrado
Laptop / tablet max-width: 1024px 2 columnas · menos padding lateral
Tablet vertical max-width: 768px 1 columna · menú apilado
Celular max-width: 480px Botones a lo ancho · tipografía más chica
⚠️ El orden importa: con max-width, escribe siempre de mayor a menor (1024 → 768 → 480). Si pones 480 antes que 1024, la regla de 1024 pisa a la de 480 y el celular se ve mal.
Así se ve tu hoja de estilos
/* base: escritorio */
.contenedor { padding: 48px; }
/* ✅ mayor → menor */
@media (max-width: 1024px) {
.contenedor { padding: 32px; }
}
@media (max-width: 768px) {
.contenedor { padding: 24px; }
}
@media (max-width: 480px) {
.contenedor { padding: 16px; }
}
🔍 Cómo probarlo: F12 → Ctrl + Shift + M y arrastra el ancho a 375, 768 y 1440.

TEMA 5

rem y html { font-size: 16px }

una medida para todo

rem significa "root em": siempre se mide contra el tamaño de letra de la raíz, es decir, del <html>. Si configuras 16px, entonces 1rem = 16px en todo el sitio.

Se configura una sola vez
/* el tamaño base de TODO el sitio */
html {
font-size: 16px;
}
/* de ahí en adelante, todo en rem */
h1 { font-size: 2.5rem; } /* 40px */
p { font-size: 1rem; } /* 16px */
.card { padding: 1.5rem; } /* 24px */
✅ La ventaja

Si cambias 16px por 18px, todo el sitio crece proporcionado: no tocas nada más.

❌ El error típico

Poner html { font-size: 10px } para "calcular fácil". Rompe el zoom y la accesibilidad.

Calculadora rem → px 1rem = 16px
1.5rem = 24px
